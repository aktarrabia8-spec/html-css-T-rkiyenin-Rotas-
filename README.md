## Türkiye'nin Rotası

**Türkiye'nin Rotası**, Türkiye'nin doğal, tarihi ve kültürel güzelliklerini keşfetmek isteyenler için hazırlanmış modern ve responsive bir gezi/rota web sitesi tasarımıdır.

Projede Türkiye'nin farklı bölgelerindeki dikkat çekici destinasyonlar tanıtılırken; kullanıcıların rotaları inceleyebileceği, gezgin yorumlarını okuyabileceği ve iletişim formu üzerinden bilgi alabileceği sade ve kullanıcı dostu bir arayüz tasarlanmıştır.

## ✨ Özellikler

* 🏠 Modern ana sayfa ve hero bölümü
* 🗺️ Farklı gezi rotalarının tanıtımı
* 🏞️ Doğal ve tarihi güzellikler için görsel kartlar
* 💬 Gezgin yorumları bölümü
* 📩 İletişim formu
* 📱 Responsive tasarım
* 🎨 Doğadan ilham alan renk paleti
* 🔤 Google Fonts ile özel yazı tipleri
* ✨ Hover ve geçiş efektleri

## 🛠️ Kullanılan Teknolojiler

* **HTML5**
* **CSS3**
* **Google Fonts**
* **Responsive Web Design**

## 🎯 Projenin Amacı

Bu proje, HTML ve CSS kullanarak modern, düzenli ve görsel açıdan etkileyici bir seyahat web sitesi oluşturma amacıyla geliştirilmiştir. Aynı zamanda responsive tasarım, CSS Grid, Flexbox, değişkenler ve modern CSS özelliklerini uygulamalı olarak kullanmayı hedeflemektedir.
